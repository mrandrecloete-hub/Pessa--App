# Security notes (honest status)
Implemented and tested: scrypt hashing, password policy, account lockout (5 failures, 15 minutes), per-route rate limiting (disabled only when NODE_ENV=test), refresh rotation with reuse detection, httpOnly SameSite=Strict cookies (Secure in production), helmet headers, DTO whitelisting that rejects unknown fields, server side role and ownership checks, audit log for sign in, business, programme and readiness actions, error responses without stack traces.
Not implemented yet: multi-factor authentication, password recovery and email verification, malware scanning and private object storage (Document Vault), encryption of sensitive local data on mobile, backup and recovery procedures, a CSRF token (mitigated by SameSite=Strict and same origin proxy), security monitoring, a penetration test.
This product does not claim to be fully secure or legally compliant. Obtain qualified Namibian legal advice before launching sensitive financial or institutional workflows.
